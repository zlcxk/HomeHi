# 数据、导出与备份

## 我的数据在哪里

- 结构化数据（记录、日程、待办、成员、设置等）在 SQLite 数据库里，默认路径 `data/homehi.db`。
- 照片、视频和议题附件默认在 `storage/` 目录；如果管理员切换到阿里云 OSS，新文件会写入 OSS，历史文件仍按上传时的后端读取。
- 这两部分都在你自己的服务器或 NAS 上，不经过任何第三方统计或云服务。

## 完整导出（默认关闭）

「设置 → 数据 → 导出全部数据」会下载一个 ZIP：

- `homehi-data.json`：完整结构化数据
- `media/`：原始照片、视频和缩略图
- `topics/`：议题附件
- `README.txt`：说明

注意：

- 这个功能默认关闭。需要部署管理员在 `.env` 中设置 `DATA_EXPORT_ENABLED="true"` 并重启服务。
- 只有家庭管理员（OWNER）可以导出。
- 导出内容包含私密照片和记录，请保存到安全的位置。
- 每次导出都会写一条审计记录（谁、何时、结果），但不会记录文件内容。
- 导出通过鉴权接口实时打包，不会落在网站的公开目录里。

## 备份由部署管理员负责

HomeHi 内置备份命令，但它需要在服务器上执行，通常由部署管理员配置定时任务：

```bash
npm run backup
```

- 数据库使用 `VACUUM INTO` 生成一致性快照，即使服务正在运行也不会得到撕裂的数据库。
- 同时复制本地 `storage/`。使用 OSS 时，媒体不在备份里，需要依赖 OSS 的版本控制或跨区域复制。
- 默认保留最近 7 份（`BACKUP_KEEP`）。
- 备份文件包含全家人的照片和数据库，默认权限只允许运行备份的系统用户读取。

恢复使用：

```bash
npm run restore -- backups/homehi-YYYYMMDD-HHMMSS --force
```

恢复前必须停止 web 和 worker；脚本会保留当前数据库和本地媒体（`*.before-restore-*` 与 `pre-restore-*-storage`），再写入备份。详细步骤见[部署指南的备份与恢复](../deployment/backup-restore.md)。

## 我能自己下载一份吗

如果管理员开启了导出，可以。否则请让管理员在服务器上执行备份，或临时开启 `DATA_EXPORT_ENABLED` 后导出，用完再关闭。

## 删除与回收站

删除的记录先进入「回收站」，可以恢复。彻底删除后无法恢复。备份可以覆盖误删，但需要管理员执行恢复，且会回退到备份时间点。
