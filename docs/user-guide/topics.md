# 家庭议题

家庭议题用来把「需要一起商量的事」放在一个地方：买房、装修、旅行计划、孩子上学、父母的医疗安排等。它不是公开论坛，也不抓取外部内容，所有信息只在当前家庭空间里。

## 一个议题包含什么

| 内容 | 用途 |
| --- | --- |
| 议题与背景 | 标题和说明，创建人默认是发起人 |
| 想法 | 随时补充的自由文本，按时间倒序 |
| 意见 | 赞成 / 再看看 / 有顾虑，附一句话理由 |
| 链接 | 攻略、报价、小程序分享文案等 |
| 附件 | 合同、报价单、照片等文件 |
| 重要日期 | 出发、截止、交房等日期 |
| 关联待办 | 关联家庭里已有的待办，不复制新的 |
| 决定与结果 | 最终决定和后续结果，记录后议题标记为「已决定」 |

## 状态

- **讨论中**：议题开放，家庭成员可以继续补充。
- **已决定**：已有决定并关闭。
- **已结束**：已关闭但没有记录决定。

重新打开一个已决定的议题不会清空决定，决定会作为历史保留。

## 粘贴分享链接

可以直接把小红书、抖音、B 站、微博、知乎等 App 的分享文案粘贴进来。HomeHi 会提取其中的第一个 http/https 链接，并尽量从文案里取标题。微信小程序链接无法在浏览器里直接打开，页面会提供「复制」按钮，粘贴到微信即可。

同一议题里相同网址只会保存一次。

## 权限

- 议题创建人或家庭管理员可以记录决定、结束 / 重新打开、删除议题。
- 单条内容的创建人可以删除自己的内容；议题创建人和管理员可以删除任意内容。
- 关联待办时会校验可见性：别人设为「仅自己」的待办不会出现在选择列表里。

## 附件

附件走统一的存储层，支持本地目录或阿里云 OSS，大小受 `MAX_UPLOAD_MB` 限制。下载时必须登录并属于同一家庭，响应会强制作为附件下载，避免浏览器把上传的 HTML/SVG 当成页面执行。
