# 常见问题

## 登录与账号

### 忘记密码怎么办？

HomeHi 没有公开的「忘记密码」邮件流程，也没有开放注册。请先联系家庭管理员确认账号状态。如果管理员也无法登录，只能由部署管理员在服务器上处理数据库；普通成员无法自行重置。

建议把密码保存在密码管理器中，并在「设置 → 账户」定期更换。

### 为什么登录后马上又回到登录页？

通常是 Cookie 的 `Secure` 设置与访问方式不一致：

- 用 `http://192.168.x.x:3000` 这种局域网 HTTP 地址访问时，`COOKIE_SECURE` 必须是 `false` 或留空。
- 通过 HTTPS 反向代理访问时，确保代理传递 `X-Forwarded-Proto: https`，或显式设置 `COOKIE_SECURE="true"`。

### 修改密码后其他设备被退出了？

这是预期行为。修改密码会让其他设备上的旧会话立即失效，当前设备保持登录。

### 成员被移除后会怎样？

该成员的登录立即失效，已创建的内容保留在家庭空间里。被移除的账号仍占用原邮箱，目前界面无法用同一邮箱重新添加；确需恢复时请联系部署管理员处理数据库，不要自行修改正在使用的数据。

## 权限与隐私

### 可以公开分享某条记录吗？

不可以。HomeHi 没有公开链接或公开主页，内容只在家庭空间内可见。可见范围只有「家庭可见」和「仅自己」两种。

### 「仅自己」的内容别人真的看不到吗？

列表、详情、搜索、相册、媒体接口都执行同一套可见性判断。别人即使知道媒体 ID，也不能通过接口读取你的私密照片。管理员导出是整个家庭的备份，会包含私密内容，界面和文档都明确提示了这一点。

### 一个实例能服务多个家庭吗？

不能。一个实例就是一个家庭。需要多个家庭请部署多个实例。

## 照片与视频

### 照片上传后没有缩略图？

图片变体由 web 和 worker 后台生成。先确认 worker 是否在运行，然后等待一段时间。缩略图失败不会影响原图打开和下载。

### 视频没有封面或无法在线播放？

视频封面与 H.264 播放版依赖 ffmpeg。缺少 ffmpeg 时视频仍可上传、原文件仍可下载，但没有封面和压缩版。部署管理员可以检查 worker 日志和 `FFMPEG_PATH`。

### 使用 OSS 后旧照片打不开？

切换存储只影响之后上传的新文件。历史文件按上传时记录的后端读取，所以本地目录和 OSS 需要同时保留。删除本地 `storage/` 前请确认没有历史文件仍在使用本地存储。

## 提醒

### 为什么提醒没有发出来？

按顺序检查：

1. 服务器上 worker 进程是否在运行。
2. 「设置 → 邮件」是否配置了完整的 SMTP，并成功发送测试邮件。
3. 自己的「设置 → 通知」是否关闭了对应类型。
4. 提醒记录里的失败原因（SMTP 未配置、发送失败等）。

没有 worker 或没有 SMTP 时，提醒不会送达，系统会显示失败而不是假装已发送。

## 数据与备份

### 数据会被上传到第三方吗？

不会。除了你主动配置的高德地图地点联想、SMTP 邮件和阿里云 OSS 存储外，HomeHi 不向外部服务发送家庭内容。没有统计脚本、没有广告、没有推荐流。

### 备份包含什么？

数据库一致性快照 + 本地 `storage/`。使用 OSS 时媒体不在备份里，需要单独保护 Bucket。完整导出 ZIP 则包含数据库内容和所有媒体的原文件，但默认关闭。

### 可以迁移到另一台机器吗？

可以。在新机器部署同版本，停止服务，把 `data/`、`storage/` 和 `.env` 迁移过去，再启动。务必先做备份。数据库迁移会随启动自动执行。

## 部署与架构

### 支持 ARM64 或树莓派吗？

不支持。HomeHi 只发布 AMD64（x86_64）镜像，部署脚本会在 ARM64 上直接退出。

### 可以不用 Docker 吗？

可以。安装 Node.js 22，执行 `npm ci && npm run build`，再分别运行 web 和 worker。生产环境必须让 worker 常驻。
