# 日历、待办与提醒

## 日程

在「日历」里可以创建一次性或重复日程：

- 标题、说明、地点
- 开始与结束时间；也可以设为全天事件
- 公历或农历（农历需要填写农历月、日，可选闰月）
- 重复：每天 / 每周 / 每月 / 每年，可设置间隔和结束日期
- 可见范围：家庭可见 / 仅自己
- 提醒：可添加多个「提前 N 分钟」

全天事件在提醒时按家庭时区的当天 09:00 处理。修改日程时间会刷新尚未发送的提醒；取消日程会取消对应提醒。

## 待办

「待办」适合家务、采购、维修这类事项：

- 标题、说明、地点、截止时间
- 优先级：普通 / 重要
- 负责人
- 重复规则
- 提醒

完成一次重复待办不会结束整个系列：系统会写入一条完成记录（谁、何时完成），并把下一次时间推进到下一个周期。历史完成记录保留在待办详情里。

## 提醒是怎么发出来的

提醒不是浏览器推送，而是由服务器上的 **worker 进程**发送邮件：

1. 管理员在「设置 → 邮件」配置 SMTP，并发送测试邮件确认。
2. 保存日程或待办时，系统会把提醒生成为一条条待发送的通知。
3. worker 到点后通过 SMTP 发信；失败会按 5 / 15 / 45 / 120 分钟退避重试，最多 5 次。
4. 每个成员可以在「设置 → 通知」里选择是否接收日程、待办和其他提醒。

如果 SMTP 没有配置，提醒记录会明确显示失败原因，而不会假装已发送。只有 web 没有 worker 时，提醒不会送达。

## 「今天」和「那年今天」

「今日」页汇总当天的日程、待办和最近的记录，并自动找出往年同一天的内容。它不计算活跃度，也不做排行榜，只回答两个问题：今天要做什么、最近发生了什么。
