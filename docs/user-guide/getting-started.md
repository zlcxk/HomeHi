# 快速上手

## 第一次进入

部署完成后，打开 `http://<服务器地址>:3000`。

- 如果这是全新实例，会自动进入 `/setup`：填写家庭空间名称、你的称呼、登录邮箱和密码。完成后你就是这个家庭的管理员。
- 如果已经初始化过，会进入登录页。账号由家庭管理员创建，没有公开注册入口。

密码要求：至少 8 位，且不能是 `12345678`、`password123` 这类常见弱密码。密码最长 72 个字节（bcrypt 的限制），中文约 24 个字。

登录状态会保持 30 天。修改密码或被管理员移出家庭后，其他设备上的登录会立即失效。

## 界面结构

桌面端左侧是导航，手机端底部是固定的标签栏。主要页面：

| 页面 | 作用 |
| --- | --- |
| 今日 | 今天的日程、待办、最近的记录，以及「那年今天」 |
| 时光 | 所有记录，按时间倒序，可按类型筛选 |
| 照片 | 照片墙、上传入口和相册 |
| 日历 | 月视图，查看和创建日程 |
| 待办 | 待办列表与完成记录 |
| 家人 | 家人和宠物档案 |
| 旅行 | 主题旅行与单次旅行打卡 |
| 议题 | 需要一起商量的事情 |
| 更多 / 我的 | 物品、搜索、回收站、设置 |

手机上可以把它「添加到主屏幕」，作为 PWA 使用。

## 建议的前 10 分钟

1. 在「设置 → 家庭」里确认家庭名称和时区。时区会影响日程、提醒和「今天」的边界。
2. 在「设置 → 家庭」添加家庭成员，把邮箱和临时密码通过安全的方式告诉对方。
3. 在「家人」里补齐家人或宠物的档案和生日。
4. 发一条「瞬间」，上传一两张照片试试。
5. 在「日历」或「待办」里建一个带提醒的事项。
6. 如果管理员开启了完整导出，可以在「设置 → 数据」下载一份 ZIP；默认情况下这个入口是关闭的。

## 外观

「设置 → 外观」可以在暖纸、青瓷、墨白、蜜桃、汽水、夜色、青柠之间切换，也可以跟随系统深浅色。选择保存在当前浏览器里，不影响其他成员。
