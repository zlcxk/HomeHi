# 家人、家庭与账户

## 家人与宠物

「家人」里每个人或宠物都是一份档案：

- 名字、头像、类型（人 / 宠物）
- 生日：公历或农历；农历生日会自动换算，用于生日提醒
- 加入家庭的日期
- 宠物可填写品种、毛色等信息
- 简介
- 可见范围：家庭可见 / 仅自己

账号可以关联到一份「人」档案。关联后，修改账号称呼或头像会同步到这份档案，避免两个地方各叫各的。

## 家庭成员

只有管理员（OWNER）能在「设置 → 家庭」里：

- 修改家庭名称和时区
- 添加成员：填写称呼、邮箱和临时密码
- 移除成员

添加成员不会发送邀请邮件。请通过当面、加密聊天等安全方式把邮箱和临时密码告诉对方，让对方登录后立即在「设置 → 账户」修改密码。

移除成员后：

- 对方所有设备上的登录立即失效。
- 对方创建过的记录、照片等内容会保留在家庭空间里。
- 对方关联的家人档案会解除账号关联，但档案本身保留。

家庭必须至少保留一个管理员，服务端会阻止移除最后一个管理员。

## 账户与密码

「设置 → 账户」可以修改称呼、默认可见范围和头像，也可以修改密码。

修改密码后：

- 当前设备会换发新的登录状态，保持登录。
- 其他设备上的旧登录立即失效，需要重新登录。
- 登录页不会告诉你「邮箱是否存在」，输错邮箱和输错密码的提示相同。

密码至少 8 位，不能是常见弱密码，最长 72 个字节。建议使用密码管理器生成并保存。

## 通知偏好

「设置 → 通知」控制是否接收日程、待办和其他提醒。修改后只影响之后生成的提醒。

## 外观

「设置 → 外观」提供 7 套配色和跟随系统的深浅色。外观是浏览器本地设置，不同设备可以不同。
