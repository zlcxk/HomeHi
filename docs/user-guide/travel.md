# 旅行打卡

「旅行」支持两种玩法：

| 类型 | 适合 |
| --- | --- |
| 主题旅行 | 长期收集，比如「全国博物馆」「山西古建筑」；按地点统计进度 |
| 单次旅行 | 一次具体的行程，比如「国庆去泉州」 |

## 创建旅行

- 名称、副标题、介绍
- 起止日期和状态：计划中 / 在路上 / 已完成
- 封面图
- 可见范围：家庭可见 / 仅自己

新建主题旅行时可以选择内置模板：全国博物馆、山西古建筑、四大石窟、名山、湖泊、地标。模板会预置一组地点和默认封面，之后可以自由增删。

## 地点与到访

每个旅行下可以添加地点：

- 地点名称、城市 / 地区、地址、备注
- 经纬度（配置了高德 Web 服务 Key 时可以直接联想选点，未配置时手动填写）
- 到访记录：日期、感受、照片

进度按「已到访地点 / 总地点」计算。到访记录里的照片同样遵守可见性设置。

## 链接

每个旅行可以保存攻略网页、微信小程序链接或分享文案：

- 普通网页直接打开。
- 微信小程序链接无法在浏览器里直接跳转，HomeHi 提供「复制」按钮，方便粘贴到微信打开。

## 模板的使用边界

模板只是初始地点清单，不会自动同步外部数据。地点、照片和到访记录都以你自己保存的内容为准。
