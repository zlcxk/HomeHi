## 三个基本概念

- **家庭空间**：一个 HomeHi 实例只服务一个家庭。所有内容都属于这个空间，没有公开主页，也没有陌生人。
- **家庭可见 / 仅自己**：每条记录、照片、日程、待办、档案都可以单独选择。设为「仅自己」后，其他家庭成员在列表、搜索、详情和接口里都看不到。
- **管理员与成员**：初始化家庭的人是管理员（OWNER）。管理员可以添加成员、修改家庭设置、管理存储和导出；成员可以使用全部日常功能，但看不到管理员设置。
