# 记录、照片与相册

## 时光

「时光」是 HomeHi 的主记录区，支持四种类型：

| 类型 | 适合写什么 |
| --- | --- |
| 瞬间 | 一句话、一张图，随手记下当下 |
| 手记 | 较长的文字，比如一次出游的完整记录 |
| 回顾 | 对一段时间的总结 |
| 日常 | 普通的生活记录 |

每条记录可以包含：

- 标题和正文
- 发生时间（决定它在时间线上的位置）
- 地点
- 照片和视频
- 标签
- 关联的家人档案
- 可见范围：家庭可见 / 仅自己
- 状态：草稿 / 发布

草稿不会出现在家庭时间线里，方便慢慢写。

## 照片与视频

在「照片」页可以直接上传，也可以从手机相册多选。上传后：

- 图片会生成 480px 缩略图和 960px 预览图；原图始终保留。
- 视频由后台生成封面并转码为 H.264 播放版，原视频仍可下载。
- 读取 EXIF 拍摄时间，用于按拍摄日期归档。
- 每张照片可以单独设置可见范围、收藏和说明。

如果缩略图或转码暂时失败，页面会回落到原文件，照片不会因此打不开。后台 worker 会定期重试失败的变体。

## 相册

「照片 → 相册」用于把照片整理成主题集合：

1. 新建相册，填写名称和说明。
2. 进入相册后选择照片加入。
3. 相册本身不复制文件；照片仍保留自己的可见性。设为「仅自己」的照片不会出现在其他成员看到的相册里。

## 搜索

顶部搜索会跨瞬间、照片、日程、待办、家人、物品和标签查找。搜索结果同样遵守可见性：别人的私密内容不会出现在你的结果里。

## 上传

照片页和记录编辑器都可以上传，支持一次选择多张、手机相册和拍照。

- 每个文件单独显示进度和结果；某个文件失败时只重试那一个，不会影响已经成功的照片。
- 上传成功后照片会立即出现在照片墙；手机浏览器没有提供图片类型时会按扩展名识别。
- 图片会生成 480px 缩略图和 960px 预览图；原图始终保留。视频由后台生成封面并转码为 H.264 播放版。
- 读取 EXIF 拍摄时间，用于按拍摄日期归档；没有拍摄时间时使用上传时间。
- 同一账号重复上传同一张图片会复用已有记录；不同家庭成员各自上传时各保留一份，确保每个人都能管理自己上传的内容。
- 在编辑表单里移除一张照片只是取消这次选择；如果它已经被记录或相册使用，照片本身不会被删除。

如果缩略图或转码暂时失败，页面会回落到原文件，照片不会因此打不开。后台 worker 会定期重试失败的变体。

## 回收站

删除的记录和照片会进入「回收站」，保留 30 天，期间可以恢复或提前彻底删除。

- 删除照片时，原图、缩略图和展示图都会保留，只是从照片墙、相册和资料中隐藏。原相册、记录附件、旅行到访、封面和头像关系也会保留或记录，恢复后照片回到原来的位置。
- 删除记录会保留正文、照片附件、标签和关联的家人档案；恢复后回到删除前的状态（草稿仍是草稿）。
- 如果照片仍被记录、旅行、头像或物品引用，回收站会显示“仍被 … 引用”，此时不能彻底删除。先在对应内容里解除引用，再回来清理。相册关联不阻止彻底删除，清理时会自动从相册移除。
- 超过 30 天的内容不能再恢复，会由后台自动彻底删除。也可以提前点击「彻底删除」，页面会再次确认。
- 彻底删除会清理原图、缩略图、展示图和视频播放版，之后无法恢复。清理失败时页面会显示原因，可以再次点击重试。
- 删除相册只删除相册和其中的关联，不会删除照片文件；从相册移除照片也不会删除照片。
- 回收站只展示你自己删除的内容，以及家庭可见、删除前已发布或归档的记录。其他成员的私密记录和草稿不会出现在你的回收站里。

彻底删除后无法恢复，请确认后再操作。部署管理员可以用备份找回删除前的数据，详见[备份与恢复](../deployment/backup-restore.md)。
